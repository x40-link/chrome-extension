Create a short link

First use

Set an API origin, short domain, and CreateShortLink token to begin.

Paste a bearer token that authorizes CreateShortLink. This extension cannot issue tokens.

A token is saved for this instance. Leave blank to keep it.

The browser asks for access to self-hosted API hosts. Clipboard access copies the returned link. The development token is stored locally without encryption.

A custom path may already be taken. Leave empty for a generated path.
